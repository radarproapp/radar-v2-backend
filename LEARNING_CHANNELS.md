# YouTube channels for Radar courses

_Collated 2026-10-19. Every handle below was checked by loading the channel page and reading back
its real title. Handles that did not resolve were dropped, not guessed._

**Why this list is channels, not video links.** The existing catalogue hardcodes specific video IDs
(`youtube.com/watch?v=oxDAv_D_u8c`). Single videos get deleted, renamed and go stale, and a wrong ID
is impossible to spot by reading the code. Channels are stable, and we can pull their current videos
at run time. Same reason we removed the made-up research papers: better to point at something real
than to ship something that looks right.

**One handle was already wrong.** `@ProductSchool` is not Product School — it now belongs to a
person called Werner Müller. The real one is `@ProductSchoolSanFrancisco`. If we had guessed, we
would have shipped it.

## Not added, and why

## How to keep this honest

Any channel added later should be checked the same way: load `youtube.com/@handle` and confirm the
page returns the channel title you expect. A handle that does not resolve does not go in.
